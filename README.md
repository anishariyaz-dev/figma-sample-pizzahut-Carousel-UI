# 🍕 Pizza Hut Specials Carousel UI

A beginner UI design and prototyping project created with Figma to explore interactive layouts, visual hierarchy, and animated transitions.
The Pizza Hut Specials Carousel is a desktop UI concept featuring a “Today's Special” section where users can switch between featured pizzas through an interactive thumbnail carousel.

## ✨ Key Features

- Four featured pizza selections
- Dynamic pizza images and titles
- Animated thumbnail interactions
- Smooth transitions and active indicators
- Clean layout with brand-inspired styling
